This project presents a clear and accessible framework for understanding educational inequality by combining SQL‑based data analysis with a structured visualization model. Using five key factors—literacy rate, internet access, education funding, student–teacher ratio, and youth unemployment—the system evaluates how fairly educational resources are distributed among countries. The final phase introduces a MATLAB‑generated network graph where nodes and edges are arranged using manual polar‑coordinate placement to ensure clarity. Edges are color‑coded by correlation sign and weighted by strength, helping viewers quickly identify meaningful relationships. This integrated approach transforms complex datasets into an intuitive and visually interpretable fairness analysis tool.I.
